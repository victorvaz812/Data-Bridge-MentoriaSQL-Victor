# Data-Bridge-MentoriaSQL-Victor
# 📊 Estudos em Análise de Dados: DataBridge Sql Lab 
https://github.com/ste-mendes/databridge-sql-lab

Repositório dedicado ao desenvolvimento de habilidades técnicas em análise de dados, reunindo exercícios, consultas, scripts e projetos desenvolvidos durante minha jornada de aprendizado.

O objetivo é consolidar conhecimentos, praticar a resolução de problemas e construir uma base sólida para atuar na área de dados.

## 🎯 Objetivos

- Desenvolver habilidades em SQL para consulta, manipulação e análise de dados.
- Aprender Python aplicado à análise e ao tratamento de dados.
- Explorar o Power BI para criação de visualizações e dashboards.
- Aplicar técnicas de análise de dados para identificar padrões e gerar insights.
- Praticar boas práticas de organização, documentação e versionamento de código com Git e GitHub.
- Construir gradualmente um portfólio que demonstre minha evolução técnica e capacidade de resolver problemas.

## 🛠️ Tecnologias e ferramentas

| Tecnologia | Aplicação |
|---|---|
| SQL | Consultas, filtros, agregações, joins e manipulação de dados. |
| Python | Programação, tratamento de dados e análises exploratórias. |
| Power BI | Modelagem de dados, criação de dashboards e visualização de indicadores. |
| Git e GitHub | Versionamento de código, documentação e organização dos projetos. |

*As tecnologias serão incorporadas ao repositório conforme o avanço dos estudos e o desenvolvimento de novos exercícios e projetos.*

## 📚 Organização dos estudos

O repositório será organizado de acordo com as tecnologias utilizadas e os conteúdos estudados.

### 🗄️ SQL
Exercícios e práticas relacionados à consulta e análise de dados em bancos relacionais.

**Conteúdos previstos:**
- SELECT, WHERE e ORDER BY
- Funções de agregação e GROUP BY
- JOINs e relacionamentos entre tabelas
- Subconsultas e CTEs
- Funções de janela (*Window Functions*)
- Tratamento e transformação de dados
- Análises utilizando conjuntos de dados reais

### 🐍 Python
Scripts e exercícios voltados à programação e à análise de dados.

**Conteúdos previstos:**
- Fundamentos da linguagem
- Estruturas condicionais e de repetição
- Funções e estruturas de dados
- Manipulação de arquivos
- Análise de dados com Pandas
- Limpeza e preparação de dados
- Análise exploratória de dados

### 📈 Power BI
Práticas de visualização, modelagem e apresentação de informações.

**Conteúdos previstos:**
- Importação e transformação de dados
- Power Query
- Modelagem de dados
- Relacionamentos entre tabelas
- Criação de medidas com DAX
- Indicadores e KPIs
- Desenvolvimento de dashboards interativos

### 🔎 Análise de Dados
Aplicação dos conhecimentos adquiridos para investigar problemas e extrair informações relevantes de conjuntos de dados.

**Atividades previstas:**
- Definição de perguntas de negócio
- Exploração e compreensão dos dados
- Identificação de inconsistências
- Análise de padrões e tendências
- Construção de indicadores
- Interpretação e comunicação dos resultados
